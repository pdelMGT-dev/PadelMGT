Avatar from padelmgt-design-system. Use via `window.PadelMGTDesignSystem.Avatar` (bundle loaded from the root `_ds_bundle.js`).

Circular avatar with photo or initials fallback. Wraps `.bs-avatar` from globals.css.

## Props

```ts
interface AvatarProps {
  name: string;
  photoUrl?: string;
  size?: number;
}
```
