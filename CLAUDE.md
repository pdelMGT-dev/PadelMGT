## gstack Skills

Available slash commands from gstack:

| Comando | Uso |
|---|---|
| `/office-hours` | Documenta el proyecto antes de planificar |
| `/plan-eng-review` | Revisión técnica del plan de ingeniería |
| `/plan-ceo-review` | Revisión del plan desde perspectiva de producto |
| `/review` | Code review completo del diff actual |
| `/qa` | QA completo del proyecto |
| `/qa-only` | Solo ejecuta tests sin otras revisiones |
| `/investigate` | Investiga un bug o problema específico |
| `/ship` | Prepara y envía un PR completo con changelog |
| `/cso` | Auditoría de seguridad (OWASP + STRIDE) |
| `/design-consultation` | Consulta de diseño UI/UX |
| `/design-html` | Genera variantes de diseño en HTML |
| `/health` | Check general del estado del proyecto |
| `/context-save` | Guarda contexto de la sesión actual |
| `/context-restore` | Restaura contexto de una sesión anterior |
| `/learn` | Aprende patrones del codebase actual |
| `/careful` | Modo cuidadoso para cambios de alto riesgo |
